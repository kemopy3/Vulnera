# Vulnera

**Vulnera** is a lightweight Python-based web vulnerability scanner designed for penetration testers, bug bounty hunters, and ethical hackers.

It performs automated checks for a wide range of common web vulnerabilities such as:

- SQL Injection (SQLi)
- Cross-Site Scripting (XSS)
- Local & Remote File Inclusion (LFI / RFI)
- Open Redirects
- Clickjacking
- Command Injection
- Missing Security Headers
- CSRF, Directory Traversal, Host Header Injection, and more

Features:
- Color-coded CLI interface
- Easy-to-use menu
- Outputs a JSON report in `reports/scan_report.json`

> This tool is for **educational and authorized testing** only.
